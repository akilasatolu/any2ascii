# any2ascii

画像・動画・GIFをASCIIアートに変換するWebページです。`index.html` 1枚だけで動き、変換はすべてブラウザ上で行われます。ファイルがサーバーに送られることはありません。

**デモ**: https://akilasatolu.github.io/any2ascii/

## できること

- **入力**: 画像、動画、GIF（ファイルを選ぶか、ページにドロップ）
- **色**: 白黒 / カラー
- **背景**: 黒 / 白 / 透過
- **サイズ**: 横の文字数を20〜240で調整
- **文字の種類**: 標準（10段階）、細かい（70段階）、ブロック、2値、自分で指定
- **調整**: コントラスト、明るさ、明暗の反転
- **保存**: PNG、テキスト（.txt）、HTML（カラー保持）、アニメGIF、クリップボードへのコピー

動画とGIFはプレビューで再生され、一時停止もできます。

## 使い方

1. 「画像・動画・GIFを選ぶ」から変換したいファイルを選びます。
2. 色・背景・サイズなどを調整します。結果はすぐにプレビューへ反映されます。
3. 「ダウンロード」から保存形式を選びます。

### 保存の詳細

- **PNG**: 「保存する画像の大きさ」（1〜3倍）で出力サイズを変えられます。背景が透過のときは、透明なPNGになります。
- **アニメGIF**（動画・GIFのみ）:
  - 動画は、コマ数（1秒あたり5 / 10 / 15）と長さ（最大3 / 5 / 10 / 20秒）を選べます。
  - GIFは、元のコマの間隔を保ったまま、最大で選んだ長さまで書き出します。
- **透過GIF**: 透明は「あり/なし」の2値です。そのため、文字の縁はPNGより少しギザつきます。
- **カラーGIF**: 256色のパレットを使うため、PNGより色が粗くなります。
- **HTML**: 色付きの文字を `<pre>` に並べた単体のHTMLです。

## 変換のしくみ

1. 画像を、指定した文字数×行数に縮小します。文字は縦長なので、行数は縦横比の半分を目安に決めます。
2. 各ピクセルの明るさ（コントラスト・明るさ調整後）を求め、薄い文字から濃い文字へ並べた一覧から対応する文字を選びます。
3. 選んだ文字を、1文字 6×12px のマスにcanvasで描画します。カラーのときは、元の色をそのまま文字に付けます。

GIFの読み込み（LZW展開）とGIFの書き出し（LZW圧縮）は、ライブラリを使わず `index.html` の中に実装しています。

## 注意

- 文字の表示のため、Google Fonts（IBM Plex Mono、Noto Sans JP）を読み込みます。読み込めない環境では、端末の等幅フォントで表示されます。
- 読み込める動画の形式は、使っているブラウザによって異なります。
- 大きな動画やGIFを長く・大きく書き出すと、時間がかかったりメモリを多く使ったりします。その場合は、横の文字数や保存する画像の大きさを小さくしてください。
- 読み込んだGIFは、メモリを節約するため、幅640pxに縮小して保持します。コマ数は最大600です。
